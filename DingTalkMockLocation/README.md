# 钉钉虚拟打卡 (DingTalkMockLocation)

基于 Android 开发者模式「模拟位置」功能的虚拟定位打卡工具。

## 下载安装

APK 安装包：`DingTalkMockLocation.apk`（约 6.2MB）

将 APK 传到安卓手机上直接安装即可。

## 使用步骤

### 1. 开启开发者模式
- 进入手机「设置 → 关于手机」，连续点击「版本号」7 次，开启开发者模式。

### 2. 授权模拟位置
- 进入「设置 → 系统 → 开发者选项」（部分手机在「更多设置」中）。
- 找到「选择模拟位置信息应用」或「Mock location app」。
- 选择本应用「钉钉虚拟打卡」。

### 3. 设置目标位置
- 打开应用，输入打卡地点的**纬度**和**经度**。
- 获取经纬度的方法：
  - 在手机地图 App（如高德、百度地图）中长按目标位置，查看坐标。
  - 注意：高德/百度地图使用的是 GCJ-02 坐标系，钉钉通常也使用 GCJ-02，可直接使用。
  - 若从 Google Maps 获取的是 WGS-84 坐标，可能需要转换。

### 4. 启动模拟
- 点击「启动模拟」按钮，应用会以前台服务方式持续注入虚拟位置。
- 通知栏会显示「虚拟定位运行中」。

### 5. 钉钉打卡
- 点击「打开钉钉」或手动打开钉钉 App。
- 在钉钉中进入考勤打卡页面，此时定位会显示为你设置的位置。
- 完成打卡。

### 6. 停止模拟
- 打卡完成后，回到本应用点击「停止模拟」，恢复真实定位。

## 定时打卡功能

1. 在「定时打卡」区域开启开关。
2. 设置上班打卡时间（如 08:30）和下班打卡时间（如 18:00）。
3. 勾选「仅工作日打卡」可跳过周末。
4. 到点后应用会自动启动模拟位置并打开钉钉。

**注意**：定时功能依赖系统闹钟，部分手机需要将本应用加入「电池优化白名单」并允许后台运行，否则可能被系统杀死。

## 位置收藏

- 输入经纬度后点击「收藏当前位置」，可保存常用打卡地点。
- 收藏列表中点击「使用」可快速加载坐标，点击「删除」可移除。

## 常见问题

**Q：提示「需要授权模拟位置」？**
A：请确认已在开发者选项中选择本应用作为模拟位置应用。

**Q：钉钉仍显示真实位置？**
A：
1. 确认模拟位置服务正在运行（通知栏有提示）。
2. 尝试关闭并重新打开钉钉。
3. 部分安卓版本需要同时关闭 Wi-Fi 和移动数据的高精度定位，或在系统设置中将定位模式设为「仅设备（GPS）」。
4. 确认钉钉未开启「智能定位」或「Wi-Fi 辅助定位」。

**Q：定时打卡不触发？**
A：请在系统设置中将本应用加入电池优化白名单，并允许自启动。

## 项目结构

```
DingTalkMockLocation/
├── app/
│   └── src/main/
│       ├── java/com/example/mocklocation/
│       │   ├── MainActivity.kt           # 主界面
│       │   ├── MockLocationService.kt    # 模拟位置核心服务
│       │   ├── ScheduleReceiver.kt       # 定时打卡广播
│       │   ├── PrefsManager.kt           # 本地存储
│       │   ├── FavoriteLocation.kt       # 数据模型
│       │   └── FavoritesAdapter.kt       # 收藏列表适配器
│       ├── res/                          # 布局与资源
│       └── AndroidManifest.xml
├── build.gradle
├── settings.gradle
└── build.sh                              # 命令行构建脚本
```

## 自行构建

### 使用 Android Studio
1. 用 Android Studio 打开 `DingTalkMockLocation` 目录。
2. 等待 Gradle 同步完成。
3. 点击 Run 或 Build → Build APK(s)。

### 使用命令行
```bash
cd DingTalkMockLocation
# 需要安装 JDK 17+ 和 Android SDK，并设置 ANDROID_HOME
chmod +x build.sh
./build.sh
```
